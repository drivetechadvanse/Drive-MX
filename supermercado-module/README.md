# Módulo Supermercado

Este módulo agrega la categoría `Supermercado` sin cambiar la lógica de las demás publicaciones.

Archivos:
- `supermercado-core.js`: normalización, separación de productos y conservación de la categoría.
- `supermercado-module.js`: selector de categoría y sección pública de Supermercado.
- `supermercado-module.css`: estilos exclusivos del módulo.
- `supermercado-email.js`: confirmación por correo al comprador cuando el pedido contiene productos de Supermercado.
